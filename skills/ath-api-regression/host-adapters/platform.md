# 平台内置 AI 适配

平台的 `ath_skill_rules_read` 是当前任务固定发行版本的静态规则读取工具。先读取本 Skill 的 entry，再按工作读取 generation、native-api、maintenance-and-recovery 或 platform-debug；本节为 platform-adapter。目录可选、规则已固定、正文实际读到是不同事实，不能把未读取或 unavailable 说成已应用规则。

在平台内置 AI 中，使用当前已开放的 `ath_assets`、`ath_reviews`、`ath_api_runs` 等业务工具及其真实 Schema，不寻找本地 MCP 配置或安装目录。项目发现工具可能是 `ath_projects_list`；按宿主实际目录使用。受限访问不能读取项目资料或执行业务工具，规则可读不改变这个边界；没有所需能力时保留可完成的草稿并说明缺口。

Markdown 来自本轮明确提交的文字、已验证上传后的可读内容或用户明确引用的当前有权资料。文件名、上传成功及摘要不等于正文已读。规则中的文件链接用于发现静态章节，不授予平台文件系统、Shell、任意网络、SQL或子代理能力；assets 下的合成例子不是实际目标，不是执行所需配置。

平台当前已接入的 Skill 目录决定可用性。其他旧发行规则中关于 S04 延期的阶段说明不覆盖当前已验证的目录与本次明确任务。用例设计 Skill 继续负责业务覆盖，本 Skill 负责可执行 API 内容的生成、细化和维护，调用权限与资格条件由平台统一校验。

写入前按宿主提供的可靠操作账本固定 commandId 与输入；只采用真实服务回执。工具已记录的待确认、失败或未知业务结果不能靠重新生成 ID 重发。接口调试与资格保存分别按用户明确要求办理。调试使用 `ath_api_runs/debug-start`；调试和清理由平台 Worker 执行，不从指引读取行为自动启动，不回放已发生或未知请求。
